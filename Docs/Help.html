材质继承管理器 — 使用说明

一个 UE 编辑器插件，以节点图形式可视化材质继承关系，支持批量创建共享母材质、按静态开关自动归并和更改母材质引用。

引擎要求：Unreal Engine 5.7。插件位于 Plugins/MaterialInheritanceManager/。

1. 快速开始

  1. 启动编辑器，打开菜单 TAG3Tools → 材质继承管理器
  2. 在 内容浏览器 中选中一个材质或材质实例
  3. 点击 「使用内容浏览器选中项」 按钮加载
  4. 节点图展示继承关系：右侧=母材质链，左侧=子材质链
  5. 选中图中节点 → 侧边栏显示预览和操作按钮

2. 继承关系图

从选中材质双向查找继承关系：

方向内容节点颜色
左侧（子）该材质的所有后代材质实例深绿色
中间（选中）当前选中材质蓝色
右侧（父）祖先材质链（逐级向上）深蓝色

节点只显示材质名称 + 类型（材质 / 材质实例），把鼠标移上去可以查看完整路径和静态开关组合。连接线（浅蓝色）表示继承方向。

操作

  • 双击节点 — 在材质编辑器中打开
  • 选中节点 — 侧边栏显示预览和操作按钮
  • 框选多个子节点 — 用于批量操作
  • 滚轮缩放 / 中键拖拽 — 图导航

3. 创建共享母材质

选中 2 个以上的同一个母材质下的子材质实例节点，把它们合并到一个共同的母材质下面。

  1. 在图中框选目标子材质实例节点
  2. 点击侧边栏 「创建共享母材质」
  3. 预览确认：显示各参数的众数值（最常见值）
  4. 确认后自动创建共享母材质，子实例重新指向它

参数策略：

  • 统计所有选中的子材质实例的 Scalar / Vector / Texture / StaticSwitch 参数
  • 取每个参数的众数作为共享母材质 的默认值
  • 子材质实例只保留与默认值不同的参数覆写

4. 更改母材质

把选中的其余材质实例，统一改成以第一个选中的材质作为它们的母材质：

  1. 在图中框选多个节点，第一个选中的 = 新的母材质，其余 = 要改母材质的对象
  2. 点击侧边栏 「更改母材质」
  3. 确认后，其余材质实例的母材质会被统一改成第一个选中的材质（不会删除任何材质，参数保持不变）

5. 自动按开关归并

检测当前材质下静态开关组合完全相同的材质实例组，自动为每组创建一个共享母材质：

  1. 加载材质后点击 「执行自动归并」
  2. 插件自动分组并创建对应的共享母材质
  3. 所有同组实例统一指向对应的共享母材质

6. 侧边栏与预览

材质预览

选中图中节点 → 侧边栏顶部显示材质球预览图（120×120）、名称、路径，以及三个操作按钮：

  • 查看继承 — 以该材质为中心重构图
  • 编辑 — 在材质编辑器中打开
  • 浏览 — 在内容浏览器中定位

操作面板

侧边栏包含完整操作入口：共享母材质、更改母材质、自动归并、设置。

7. 设置与性能

设置项默认值说明
输出目录当前材质的文件夹 / MI_AutoGenerated自动创建的子材质保存位置；在设置里留空时使用这个默认位置
命名前缀MI新材质实例的名称前缀
展示层级4每侧最大查找深度
最大节点数200图中最大节点数量限制
性能说明：使用 AssetRegistry 依赖查询而非全量加载，1000+ 节点也能在亚秒级构建。节点数受上限保护。
